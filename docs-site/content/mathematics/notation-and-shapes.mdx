## Conventions

These are how the code arranges its numbers, not general rules about transformers.

- **A token is a row.** One token's vector is a row with `d` numbers.
- **A sequence is a matrix.** A sequence of `T` tokens has shape `[T x d]`.
- **A linear layer is `X @ W + b`.** `X` is on the left, so `W` has one row per input feature. The bias `b` is added to every row.
- **There is no batch axis.** `forward` and `loss_and_grads` take one sequence at a time. `batch_loss_and_grads` in `train.py` is a Python loop over the windows of a batch (<CodeLine id="notation.batch-loop" />).
- **Heads add one axis.** Multi-head attention works on `[H x T x d_h]`. The head comes first.
