## What this project is

This project is a small language model written from scratch in Python and NumPy. Its forward and backward passes are written by hand, with no automatic differentiation. This site documents its mathematics and its code.

The values below come from `config.py`:

- <ConfigValue name="num_layers" /> transformer blocks.
- <ConfigValue name="num_heads" /> attention heads, each of width <ConfigValue name="head_dim" />.
- Width <ConfigValue name="emb_dim" /> through the model, and <ConfigValue name="ff_dim" /> inside the feed-forward step.
- Training windows of <ConfigValue name="seq_len" /> tokens.

The vocabulary size is not a config value, because it depends on the corpus. Besides NumPy, `data.py` uses `pandas` to read the corpus and to hold the training windows.

The optimizer is the `Adam` class in `optim.py`. Training gives it a weight decay of <ConfigValue name="weight_decay" />, applied separately from the gradient, so it behaves as AdamW. See <PageLink page="training/adamw-learning-rate-clipping">AdamW / Learning Rate / Clipping</PageLink>.

## How to read this site

### The layout

Each page has three columns. The left column lists every section and page. The middle column is the page itself. The right column, "On this page", lists the headings of the current page and follows your position as you scroll.

To search concepts, equations, pages, files and functions, use the Search button at the top, or press Ctrl+K or `/`.

### The sections

- **Mathematics** explains each operation the model uses, from notation and tokenization to the full model. Each one has its equation, a small worked example, its tensor shapes and its code.
- **Training** covers how gradients reach the parameters, how the optimizer updates them, and the training loop.
- **Generation** covers sampling a token and repeating that to produce text.
- **Code** shows every source file with its real lines, and covers checkpoints and the test suite. **Testing**, next to it, covers gradient checking.
- **Reference** collects every equation in one table, and records what the model leaves out and where the sources disagree.

Every page also has previous and next links at the bottom, which follow the sidebar.

### From an equation to its code

Each equation has a **Show code** button. It highlights the lines that compute the equation and scrolls to them. A marked code line works the other way, and shows which equations it belongs to. Line numbers and GitHub links come from a pinned commit, and are generated from the code, not typed by hand.

## Labels on this site

- **Illustrative Example** means the numbers are hand-picked to show how a calculation works, and
  they are not learned values.
- **Actual Model Output** means the numbers were produced by running this repository's code.
- **Derived from implementation** means the code implements this mathematics, and the reference PDF
  does not state it.
